# PopScope — новости о знаменитостях и поп‑культуре

Запуск локально:

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

Структура:
- `public/index.html` — главная страница
- `public/styles.css` — стили
- `public/script.js` — логика загрузки, фильтров, модалок и галереи
- `public/news/*.json` — отдельные новости в формате:

```json
{
  "title": "Заголовок новости",
  "subtitle": "Подзаголовок",
  "date": "2025-08-12",
  "category": "Музыка",
  "images": ["photo1.png", "photo2.png"],
  "content": ["Абзац 1", "Абзац 2"]
}
```

Изображения:
- Положите `.png`-файлы в `public/images/` и указывайте имена в `images` каждой новости.
- Сейчас используются визуальные плейсхолдеры: если файл картинки отсутствует или невалидный, блок показывает заглушку.
- Рекламные баннеры: `images/alpha-vert.png` (вертикальный), `images/alpha-inline.png` (малый). Если их нет — отрисуются заглушки, ссылки активны.

API и статика:
- Локально можно использовать `GET /api/news` (Express) — агрегирует все `*.json` из `public/news` и сортирует по дате.
- Для GitHub Pages нет серверной части. Используется статический файл `public/news/index.json`, который уже содержит агрегированный список новостей. Фронтенд сначала пробует `api/news`, если недоступно — читает `news/index.json`.

Размещение на GitHub Pages:
- GH Pages должен обслуживать папку, где лежит `index.html` (корень репозитория или `/docs`).
- Варианты:
  - Переместите содержимое `public/` в корень репозитория; включите Pages: Branch `main`, Folder `/`.
  - ИЛИ переименуйте `public/` в `docs/`; включите Pages: Branch `main`, Folder `/docs`.
- Внутренние пути сделаны относительными (`styles.css`, `script.js`, `images/...`), поэтому сайт корректно работает по адресу вида `/username/repo/`.

Примечания:
- Фильтр по категориям работает без перезагрузки.
- Лайтбокс по клику на фото внутри статьи.
- Адаптивная верстка для desktop/tablet/mobile.
